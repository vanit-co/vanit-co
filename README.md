# vanit-co

vanit-co site: one page in English (`index.html`) and in Portuguese
(`pt-br/index.html`), built with Vite and Tailwind.

```sh
npm install
npm run dev       # http://localhost:5173
npm run build     # both pages into dist/
```

The Lichen screenshots in `static/images/lichen/` are crops of the console's
own screenshots, converted to webp.
